# Backup Import and Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one-click full ZIP export and one-file full ZIP import for navigation data and the optional background image.

**Architecture:** A focused `backup.go` module owns the versioned ZIP format, strict archive validation, and transactional restore. Authenticated HTTP routes remain in `main.go`; Vue exposes two direct edit-mode actions with no format choices or confirmation dialogs.

**Tech Stack:** Go 1.23 standard library (`archive/zip`, `encoding/json`, `net/http`), Vue 3 local runtime, Go `testing`.

- [ ] **Step 3: Implement strict archive parsing**

Add these limits and functions in `backup.go`:

```go
const (
    maxBackupUpload     = 8 << 20
    maxBackupEntries    = 3
    maxBackupNavigation = 512 << 10
    maxBackupBackground = 5 << 20
)

type importedBackup struct {
    Navigation Navigation
    Background []byte
    Extension  string
}

func parseBackup(raw []byte) (importedBackup, error)
func readZipEntry(file *zip.File, limit int64) ([]byte, error)
func backgroundExtension(data []byte) (string, error)
```

Accept only the exact root names `manifest.json`, `navigation.json`, and one optional supported `background.<ext>`. Reject directories, duplicate names, unknown names, more than three entries, size-limit violations, mismatched image extension/MIME, invalid manifest format/version, invalid navigation JSON, and navigation data rejected by `validate`.

- [ ] **Step 4: Implement transactional restore**

Add:

```go
func (a *App) restoreBackup(imported importedBackup, expectedRevision string) (Navigation, string, error)
```

Under `a.mu`, compare the current revision, write a new content-addressed background file before switching navigation, set `BackgroundImage` from its digest, atomically write navigation with `writeData`, then remove old background files. If navigation writing fails, remove the staged background and leave existing files intact.

Route authenticated multipart `POST /api/backup` in `main.go`. Limit the request body, require form file `backup` and form value `revision`, parse and restore, return `409` for revision conflicts, and otherwise return updated `categories`, `backgroundImage`, and `revision`.
