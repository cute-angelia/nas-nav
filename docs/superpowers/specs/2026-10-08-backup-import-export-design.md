# 完整备份导入导出设计

## 目标

为已登录用户提供简单的完整备份能力。编辑模式下只显示“导入”和“导出”两个动作，不提供格式、范围或合并策略选项。

## 用户流程

### 导出

1. 用户点击“导出”。
2. 浏览器立即下载一个完整备份 ZIP。
3. 不显示范围选择或确认弹窗。

### 导入

1. 用户点击“导入”并选择一个 ZIP 文件。
2. 选择完成后立即上传、校验并整体恢复。
3. 不显示覆盖确认、合并选项或内容选择。
4. 成功后页面重新加载数据并显示成功提示；失败时显示具体错误，原数据保持不变。

## 备份格式

ZIP 使用版本化格式，只允许包含：

- `manifest.json`：格式标识、格式版本和导出时间。
- `navigation.json`：导航分类、网址和数据版本。
- `background.jpg`、`background.png`、`background.gif` 或 `background.webp`：可选背景图片，只允许存在一个。

备份不包含密码、`.env`、Cookie、会话或服务器配置。导入时不信任 `navigation.json` 中的背景地址；服务端根据实际图片重新生成背景 URL。

## 接口

- `GET /api/backup`：要求有效登录会话，返回 `application/zip` 和下载文件名 `nas-nav-backup-YYYYMMDD-HHMMSS.zip`。
- `POST /api/backup`：要求有效登录会话、同源校验和 `X-Nav-Request: 1`。使用 multipart 上传 `backup` 文件，并携带当前 `revision`。
- 导入成功返回最新的 `categories`、`backgroundImage` 和 `revision`，前端直接替换当前状态。
- 当前 revision 已变化时返回 `409`，避免旧页面覆盖其他页面的新修改。

## 安全与一致性

- 限制上传体积、ZIP 文件数量、单文件解压体积和总解压体积。
- 只接受固定文件名，拒绝目录、绝对路径、路径穿越、重复条目和未知条目。
- 使用现有数据校验规则验证导航 JSON，使用 MIME 检测验证背景图片。
- 先将全部内容写入临时文件并完成校验，再切换正式数据。
- 新背景使用内容摘要生成地址；导航文件成功切换后再删除旧背景。
- 任一步骤失败时清理临时文件，并保持原导航与背景不变。

## 前端

- “导入”和“导出”仅在编辑模式工具栏显示。
- “导出”直接请求备份并触发下载。
- “导入”使用隐藏文件输入，仅接受 ZIP；选中文件后立即上传。
- 上传期间沿用现有 busy 状态，避免重复操作。
- 结果使用现有 toast 展示，不增加模态确认框。

## 测试

- 完整备份导出并恢复导航和背景。
- 无背景备份可以正常导出和恢复。
- 未登录用户不能导入或导出。
- 损坏 ZIP、未知条目、路径穿越、重复条目、超限内容和非法背景被拒绝。
- revision 冲突返回 `409`。
- 导入失败后原导航和背景保持不变。
- 前端不包含覆盖确认或导出范围选择。

## 非目标

- 不支持合并导入。
- 不支持只导出 JSON。
- 不支持选择性恢复。
- 不支持导入其他导航产品的格式。
