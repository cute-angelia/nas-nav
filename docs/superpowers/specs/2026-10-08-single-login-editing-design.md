# 单次登录编辑设计

## 目标

用户通过页面密码登录后即可编辑导航内容。点击“编辑”不再要求再次输入密码，“完成”只退出前端编辑界面，不改变登录状态或服务端写权限。

## 权限模型

- 登录是唯一认证步骤。
- 已登录会话可以读取和修改导航数据、上传或清除背景图片。
- 未登录请求继续无法读取或修改私人导航数据。
- 前端 `editing` 只控制编辑按钮、表单和拖动控件的显示，不代表额外的服务端授权。

## 前端变更

- 点击“编辑”直接将 `editing` 切换为 `true`。
- 点击“完成”直接将 `editing` 切换为 `false`。
- 删除编辑密码字段、二次解锁弹窗及其提交逻辑。
- 服务端返回未登录时，退出登录状态和编辑状态。

## 后端变更

- 删除会话中的编辑授权过期时间。
- 删除 `/api/edit/unlock` 与 `/api/edit/lock`。
- 保存导航数据、上传背景和清除背景只验证有效登录会话。
- 保留现有 CSRF、同源请求、内容类型、请求体大小和数据校验。

## 文档与测试

- README 改为“登录后点击编辑即可修改”。
- 接口测试覆盖：未登录写入被拒绝，登录后无需二次解锁即可写入。
- 背景图片测试覆盖：登录后无需二次解锁即可上传和清除。
- 前端测试或静态断言确认编辑密码界面和解锁请求已移除。

## 非目标

- 不取消页面登录密码。
- 不改变会话 Cookie、登录限流或退出登录行为。
- 不改变导航数据格式和已有数据。
